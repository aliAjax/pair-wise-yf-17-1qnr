# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

做一个给管风琴维护人员使用的音管调音记录前端项目，可以记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注。页面需要有音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页。

## 功能与业务规则

- 页面包含五个部分：调音偏差表（含数据录入）、音栓列表、温湿度记录、异常音管标记、单次维护报告。
- 每次维护可记录多支音管的音高、音分偏差、温湿度、簧片状态和维修备注。
- 偏差达到 ±8 音分或簧片标记异常的音管自动进入「待复核」。
- 异常音管的维修备注写清楚（非空）后才能确认复核，否则确认按钮不可用。
- 复核通过后报告锁定：音管编号、测量数据与备注不可再修改，场馆状态由「进行中」转为「已完成」。
- 同一音管编号再次录入视为复测：保留新值，旧值标记为「已替换」；异常标记、数量汇总与场馆筛选均以最新复测值为准。
- 数据保存在浏览器 localStorage，可点击左侧「恢复示例数据」重置。
